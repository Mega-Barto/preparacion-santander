- Priorizar fondos limpios y espacios en blanco.

- No modificar los colores del logotipo original.

## 4. Tipografía

**Familia tipográfica propuesta: Ubuntu Font Family**

Ubuntu es una familia tipográfica libre, desarrollada para el proyecto Ubuntu, con una estética contemporánea y excelente legibilidad en pantallas.

### Variantes recomendadas

| Familia | Uso |
|---|---|
| Ubuntu Light | Textos secundarios y descripciones |
| Ubuntu Regular | Párrafos y contenido general |
| Ubuntu Medium | Subtítulos |
| Ubuntu Bold | Titulares y destacados |
| Ubuntu Condensed | Espacios reducidos |
| Ubuntu Mono | Datos técnicos y códigos |

### Descargas oficiales

- [Ubuntu Font Family — Canonical](https://design.ubuntu.com/font)
- [Ubuntu Design Resources](https://design.ubuntu.com/resources)
- [Ubuntu Sans — GitHub](https://github.com/canonical/Ubuntu-Sans-fonts)
- [Ubuntu Sans Mono — GitHub](https://github.com/canonical/Ubuntu-Sans-Mono-fonts)

### Implementación web

```css
@import url('https://fonts.googleapis.com/css2?family=Ubuntu:wght@300;400;500;700&display=swap');

:root {
  --font-primary: 'Ubuntu', sans-serif;
}

body {
  font-family: var(--font-primary);
  font-weight: 400;
}

h1, h2, h3 {
  font-weight: 700;
}
```

## 5. Lineamientos de uso

### Logotipo

- Mantener las proporciones originales.
- Respetar el espacio de seguridad.
- No aplicar deformaciones ni rotaciones.
- No cambiar los colores originales.
- Evitar fondos que dificulten su legibilidad.

### Fotografía

Priorizar imágenes que comuniquen:

- Experiencias cotidianas en el hogar.
- Productos en contextos reales de uso.
- Ambientes modernos, cálidos y funcionales.
- Personas interactuando naturalmente con los productos.

### Comunicación

La comunicación debe transmitir:

- Cercanía.
- Confianza.
- Innovación.
- Practicidad.
- Bienestar.
- Calidad.
